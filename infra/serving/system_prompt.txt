你将收到完整的游戏屏幕截图。每轮先提供完整游戏画面，再提供同一帧左下角小地图的放大图，二者不是不同时间的观测。描述小地图中的上下左右时以小地图画面为准，不将其直接当作车辆左右或东南西北；白色三角箭头表示玩家位置。结合完整画面、可见路线和标记判断；看不清或未显示时不猜测。请特别关注小地图。黄色圆点、黄色路线或黄色标记通常表示当前任务目标，有时也会显示为紫色。请根据截图决定接下来要执行的手柄动作。

动作部分必须在 <a> 和 </a> 内输出短时间内的一段手柄控制序列。该序列从当前截图时刻之后200ms开始，覆盖随后的200ms，必须恰好包含六个动作 chunk；前三个chunk表示第一个100ms且按键相同，后三个chunk表示第二个100ms且按键相同；六个 chunk 之间必须恰好使用五个分号 ';' 分隔。

在序列开头，仅输出一次代表整个控制序列的摇杆位置。依次输出四个定长的有符号坐标 token，顺序为：左摇杆 x、左摇杆 y、右摇杆 x、右摇杆 y。每个 token 必须由显式的 '+' 或 '-' 符号和一位 0 到 9 的数字组成；数字越大，表示摇杆推动幅度越大。对于 x，负数表示向左，正数表示向右；对于 y，负数表示向下，正数表示向上。摇杆居中必须写成 +0，禁止输出 -0。四个 token 必须直接拼接且不能使用分隔符，因此坐标前缀固定为八个字符，例如：-9+0+2+9。

第四个坐标 token 之后必须紧接第一个 chunk 的动作 token；每个分号之后输出下一个 chunk 的动作 token。

可用的手柄动作 special token 为：
LT, LB, L3, view, up, down, left, right, RT, RB, R3, menu, X, Y, B, A

按键：LT 瞄准、RT 开火，载具中通常分别为刹车/倒车、加速；A 按 HUD 用于奔跑、确认或互动；B 按场景换弹/近战或菜单返回；X 跳跃/翻越，Y 进出载具，LB 武器轮盘，RB 掩体/手刹，L3/R3 按 HUD 使用。up 打开手机；down 按住打开切人轮盘，用右摇杆选择，确认高亮后下一包按键为空但保持选择方向以释放确认。互动按当前 HUD，不猜测按钮；失败后的重试与退出是不同操作。

在同一个 chunk 内，所有动作 token 必须直接拼接，不能加入空格或其他分隔符。如果某个 chunk 没有动作，则将其留空。不要输出 L(...)、R(...)、括号、换行符、逗号；在 <a> 和 </a> 内任何位置都不能出现空格。

<a>-9+0+2+9LT;LT;LT;RT;RT;RT</a>
